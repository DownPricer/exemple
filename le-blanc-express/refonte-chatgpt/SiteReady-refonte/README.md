# Source de la page Élégant

Placez ici le fichier **`index.html`** de la refonte ChatGPT (version d’origine, non modifiée).

Si la refonte charge un fichier **`avis.json`** en relatif, vous pouvez aussi le copier ici (sinon, ignorez).

Ensuite, à la racine du projet :

```bash
npm run build:elegant
```

Cela génère `public/elegant/index.html` (sélecteur de style, canonical, liens légaux, formulaire API) sans modifier ce dossier source.
